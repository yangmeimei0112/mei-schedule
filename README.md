# 咩時光 MeiSchedule (`v1.5.3`)

咩創意工作室（Mei Creative Studio）打造的跨五端全能智慧排程與多人共享時間軸軟體，一套統一現代化核心同時支援 **iOS、Android、macOS、Windows 與網站 (Web / PWA)**。

> **v1.5.3 行動端右下角 `+` 鈕直開空白完整新增行程表單**：點擊行動端右下角懸浮 `+` 按鈕直接開啟空白的完整「新增行程」抽屜表單（不再跳轉聚焦頂部快速輸入列），所有欄位預設空白且支援全天行程日期切換、開始時間自動推算結束時間、必填欄位驗證與取消不產生多餘行程。  
> **v1.5.2 全站主題色統一系統、Android 沉浸透視底部導覽列與共享邀請碼嚴格校驗**：建立三套主題 × 亮／深雙模式（6 種視覺世界）統一語意色系，讓所有指標圖示、品牌標誌、頂部／底部導覽列、側欄、次按鈕、勾選框、捲軸與返回大廳膠囊 100% 和諧統一（嚴格保留使用者自選的行程圖塊底色不動）；徹底消除 Android PWA 底部系統列藍色底色，升級為 Edge-to-Edge 懸浮半透明毛玻璃底部導覽列（直接透視呈現 App 內容）；強化共享日曆 6 碼邀請碼查核，輸入不存在邀請碼僅通知錯誤、絕不自動新增團隊。  
> **v1.5.1 全站行程自動換行系統與統一側欄革新**：新增系統級行程／待辦自動換行閱讀功能（`.schedule-title-wrap` 與偏好開關，三日／週視圖、月總覽、時間軸與所有抽屜自動換行顯示完整標題，不再以 `...` 截斷，且短時長排程智慧自動撐開防裁切）；整合全高統一左側側欄（可縮為 `64px` 精簡圖示軌）、單層頂欄與右側可收合待辦翼板（快捷鍵 `I`）。

> **v1.3.1 返回咩創意大廳按鈕雙重隱藏升級**：升級跨專案導覽膠囊 SDK (`mei-dock.js`) 支援「貼邊微露拉條（隱藏至螢幕邊緣，點擊極細半透明拉條即滑出）」與「完全隱藏」模式，並於「外觀設定」與全域指令列 (`Cmd/Ctrl + K`) 內建即時同步切換開關與狀態記憶。

## 核心特色

1. **五大排程視角無縫切換**
   - 沉浸式單日時間軸（含可用空檔提示、子任務勾選、提早完成釋放空檔、手機防誤觸 `-15m / +15m` 微調）
   - 三日視圖與週視圖多欄網格（自動防重疊並排、支援待辦與行程拖曳改期）
   - 手機友善月總覽（所有螢幕尺寸皆完整顯示語意色彩條與事件標題，絕不只顯示灰點）
   - 依日期分組與即時關鍵字篩選清單視角
2. **中英文自然語言快速輸入**
   - 直接輸入「明天下午3點半跟產品團隊開會 90分鐘 #工作 每週三 !高」或英文語句，即時解析日期、時間段、時長、色標與重複規則。
3. **五大旗艦生產力模組**
   - **專注番茄鐘、無版權輕音樂與時間統計儀表板**：圓形進度環計時、4 首原創離線療癒輕音樂＋自然環境音雙軌混音＋本機音檔匯入、背景專注迷你控制膠囊、連續專注天數（Streak）與分類時間投入佔比。
   - **智慧排程助手與「預覽重排」模式 (Preview Mode)**：未排待辦一鍵自動填入空檔、延誤衝突智慧順延彈性區塊（嚴格保護鎖定會議），所有變更皆先呈現前後差異預覽，確認套用後支援 50 層原子一鍵復原（Undo / Redo）。
   - **標準日曆互通**：完整支援 RFC 5545 `.ics` 檔案／文字雙向匯入（自動去重）與匯出，並內建一鍵加入 Google 日曆連結。
   - **多人共享日曆與單一行程即時留言**：建立共享日曆與 6 碼邀請碼、成員角色權限管理（Owner / Editor / Viewer）、擁有者一鍵移除成員（支援復原）及單一行程即時討論串。
   - **跨五端原生通知與系統匣迷你視窗**：Electron 桌面系統匣今日快覽（`#/tray`）與全域快記快捷鍵（`Cmd/Ctrl + Shift + Space`）、Capacitor 本地排程推播與觸覺回饋。
4. **三套視覺風格 × 亮／深雙模式（6 種外觀）**
   - 預設承襲咩創意工作室「晴空 (`sky-glass`)」，內建一鍵切換「極簡 (`minimal-linear`)」與「溫暖 (`warm-journal`)」，全站嚴格零系統 Emoji、100% Lucide 向量圖示，並完整適配手機四大長寬比與動態視窗高度 (`dvh`)。
5. **本機優先離線可用 ＋ 咩創意工作室雲端帳號 SSO**
   - 免登入開箱即用（IndexedDB 離線持久化），登入咩創意工作室雲端帳號（原生 Google OAuth／信箱驗證碼註冊／Passkey）即無縫合併同步，並整合 `mei-dock.js` 返回工作室大廳膠囊。

## 快速開始

```bash
# 安裝依賴（純 Web 開發環境可略過 Electron 執行檔下載）
ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm install

# 啟動本機開發伺服器
npm run dev

# 執行完整驗證（型別檢查、單元與整合測試、Web 建置、Electron 編譯與靜態規範檢驗）
npx tsc --noEmit
npm test
npm run build
npm run build:electron:check
```
